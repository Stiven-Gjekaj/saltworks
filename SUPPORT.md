# Getting help

## Understand the project

- [README.md](README.md) says what each mod does and how to install it.
- The README in each folder under [plugins](plugins) gives the settings and the
  limits of that mod.
- [AGENTS.md](AGENTS.md) sets the rules for anybody who changes this
  repository, human or agent.
- [TERMS.md](TERMS.md) says what you agree to when you use a mod.

## Ask a question or report a problem

- Search the existing
  [issues](https://github.com/Stiven-Gjekaj/saltworks/issues) first, in case
  somebody has already asked.
- If you found a bug, open a bug report.
- If you want a feature, open a feature request.

When a guard blocks a command that it should let through, copy the exact
command and the reason that the guard gave.
Name the Claude Code version, and say where it ran: the terminal, the desktop
app or the mobile app.

Do not use the issue tracker for security problems.
See [SECURITY.md](SECURITY.md) for how to report those privately.
